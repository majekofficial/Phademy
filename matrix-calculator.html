What a matrix calculator can do

A matrix is a rectangular arrangement of numbers in rows and columns. Matrices are used to organise data, represent transformations, solve systems of equations and describe relationships in science, computing and engineering. A matrix calculator can help with common operations that are easy to get wrong when done by hand. Phademy's tool works with 2 × 2 and 3 × 3 square matrices and offers four operations: determinant, inverse, transpose and adjugate.

Choose the matrix size, select the operation, and enter each value in its labelled row and column. Whole numbers, decimals and fractions such as 1/2 are accepted. The result is displayed with working where the operation requires it. The calculator is not a general matrix package: it does not offer matrix addition, multiplication, eigenvalues or rectangular matrices. Knowing the supported operations helps you select it for the right task.

Rows, columns and matrix notation

A matrix is usually written inside square brackets. For example, A = [[1, 2], [3, 4]] has two rows and two columns. The first row is 1, 2. The second row is 3, 4. The entry in row 1, column 2 is 2, while the entry in row 2, column 1 is 3. Row and column order matters; switching the two values changes the matrix.

A matrix with the same number of rows and columns is called a square matrix. A 2 × 2 matrix has four entries, and a 3 × 3 matrix has nine. The calculator asks you to choose one of these sizes and labels every input by row and column. Entering a value in the wrong cell can change the determinant, inverse and every other result.

Operation one: determinant of a 2 × 2 matrix

The determinant is a single number calculated from a square matrix. For a 2 × 2 matrix A = [[a, b], [c, d]], the formula is det(A) = ad − bc. Multiply the top-left entry by the bottom-right entry, multiply the top-right entry by the bottom-left entry, and subtract the second product from the first.

For A = [[1, 2], [3, 4]], the determinant is (1 × 4) − (2 × 3) = 4 − 6 = −2. The answer is one number, not another matrix.

The order of the subtraction is important. It is ad minus bc, not bc minus ad. Reversing the order changes the sign of the determinant. A determinant can be positive, negative or zero. Its value gives useful information about whether the matrix has an inverse.

Determinant of a 3 × 3 matrix

For a 3 × 3 matrix, the determinant can be found by expanding along a row or column. Expanding along the first row uses alternating signs: plus, minus, plus. Each entry is multiplied by the determinant of the 2 × 2 matrix left after removing that entry's row and column.

For A = [[2, 0, 1], [1, 3, 2], [1, 1, 4]], expand along the first row: det(A) = 2(3×4 − 2×1) − 0(1×4 − 2×1) + 1(1×1 − 3×1). This becomes 2(10) + 1(−2) = 20 − 2 = 18. The determinant is 18.

The middle term is zero in this example, but the alternating sign pattern still matters. When doing the calculation by hand, write the three terms separately so that the minus sign in the second term is not lost.

What a determinant tells you

The determinant helps determine whether a square matrix is invertible. If the determinant is not zero, the matrix has an inverse. If the determinant is zero, the matrix is singular and has no inverse. In geometric terms, a matrix transformation with determinant zero collapses space into a lower dimension, so the original information cannot be recovered uniquely.

For example, [[1, 2], [2, 4]] has determinant 1×4 − 2×2 = 0. The second row is twice the first, so the rows are dependent. The matrix does not contain two independent row directions and cannot be inverted. The calculator reports that no inverse exists when the determinant is zero.

Operation two: inverse of a matrix

The inverse of a matrix is similar to a reciprocal, but it is defined through matrix multiplication. If A has an inverse A⁻¹, multiplying A by A⁻¹ gives the identity matrix I. For a 2 × 2 matrix, the identity matrix is [[1, 0], [0, 1]]. The inverse reverses the effect of the original matrix transformation.

The formula is A⁻¹ = (1 / det(A)) × adj(A). First find the determinant. Then find the adjugate. Finally divide every entry of the adjugate by the determinant. This operation is possible only when the determinant is non-zero.

For A = [[4, 7], [2, 6]], det(A) = 4×6 − 7×2 = 10. The adjugate is [[6, −7], [−2, 4]]. Divide each entry by 10 to obtain A⁻¹ = [[3/5, −7/10], [−1/5, 2/5]]. Multiplying the original matrix by this inverse gives the identity matrix.

Operation three: transpose

The transpose of a matrix is formed by turning its rows into columns. The entry in row i and column j moves to row j and column i. This operation is often written with a superscript T, so the transpose of A is Aᵀ. For a square matrix, the result has the same dimensions as the original.

If A = [[1, 2], [3, 4]], then Aᵀ = [[1, 3], [2, 4]]. The first row (1, 2) becomes the first column, and the second row (3, 4) becomes the second column. For [[1, 2, 3], [4, 5, 6], [7, 8, 9]], the transpose is [[1, 4, 7], [2, 5, 8], [3, 6, 9]].

A common mistake is to reverse the order of all entries rather than swap row and column positions. The top-left entry remains in the top-left position. The values across the main diagonal stay in place; the off-diagonal entries are reflected across that diagonal.

Operation four: adjugate

The adjugate is the transpose of the cofactor matrix. A cofactor is found by calculating a minor and applying a plus or minus sign according to its position. For a 2 × 2 matrix [[a, b], [c, d]], the adjugate has a simple form: [[d, −b], [−c, a]]. Notice that the diagonal entries swap places and the off-diagonal entries change sign.

For [[1, 2], [3, 4]], the adjugate is [[4, −2], [−3, 1]]. This is not the same as the transpose. The adjugate is especially useful because the inverse is the adjugate divided by the determinant.

For a 3 × 3 matrix, calculate the minors, apply the checkerboard cofactor signs, and transpose the cofactor matrix. The calculator displays the cofactor matrix and explains that the adjugate is its transpose. Keeping these stages separate helps you understand why the result is arranged as it is.

Fractions and exact answers

Matrix entries do not have to be whole numbers. The calculator accepts decimals and fractions such as 1/2. Fractions are useful in inverse calculations because the exact answer may not be a terminating decimal. For example, 1/3 is more precise than writing 0.333 and stopping there. If an inverse contains fractional entries, retain them until the final stage rather than rounding every intermediate value.

When entering a fraction, use a slash and make sure the numerator and denominator are clear. If a value is negative, include the negative sign with the fraction. Avoid rounding input values that were supplied exactly in a question. A small rounding difference in the entries can change a determinant or inverse and make the final result less accurate.

Worked comparison: invertible and singular matrices

Compare A = [[4, 7], [2, 6]] with B = [[1, 2], [2, 4]]. Matrix A has determinant 10, which is not zero, so it has an inverse. Matrix B has determinant zero, so it has no inverse. Both are 2 × 2 matrices, but their algebraic properties differ because their row relationships differ.

This is why it is useful to calculate the determinant before attempting an inverse. A zero determinant is not a calculator error or a missing decimal place. It is a mathematical condition that prevents an inverse from existing.

Applications of matrices

Matrices are used to solve simultaneous linear equations, transform coordinates, organise data and represent networks. In computer graphics, matrix transformations can rotate, scale or reflect points. In economics and statistics, matrices can store relationships among many variables. In physics and engineering, they can represent systems of equations and changes between coordinate systems.

The determinant and inverse are particularly important in solving square systems of linear equations. If the coefficient matrix has a non-zero determinant, the system has a unique solution under the usual square-system conditions. A singular coefficient matrix indicates that the equations do not provide a unique independent set of constraints. For direct equation solving, the Simultaneous Equations Calculator is more convenient.

Common matrix mistakes

  • Swapping entries: check the row and column label before typing each value.
  • Using the 2 × 2 determinant rule on a 3 × 3 matrix: use cofactor expansion for 3 × 3 matrices.
  • Reversing ad − bc: the order of subtraction changes the determinant's sign.
  • Forgetting the cofactor signs: the 3 × 3 sign pattern begins plus, minus, plus on the first row.
  • Trying to invert a singular matrix: an inverse exists only when the determinant is non-zero.
  • Confusing transpose and adjugate: transpose swaps rows and columns; adjugate uses cofactors and then transposes.
  • Rounding too early: keep exact fractions during intermediate calculations.

What this calculator does not cover

This tool is limited to square 2 × 2 and 3 × 3 matrices and the four listed operations. It does not currently calculate eigenvalues, eigenvectors, matrix products, matrix sums, row-reduced echelon form or determinants of larger matrices. If your course question asks for one of those operations, use the method taught in your class or an appropriate tool. Do not assume that a result for a 3 × 3 matrix can be extended automatically to a larger matrix.

Frequently asked questions

What is the determinant of a matrix?

It is a single number calculated from a square matrix. For a 2 × 2 matrix [[a, b], [c, d]], it is ad − bc.

When does a matrix have an inverse?

A square matrix has an inverse if and only if its determinant is not zero. A zero determinant means the matrix is singular.

What is the difference between transpose and adjugate?

The transpose swaps rows and columns. The adjugate is the transpose of the cofactor matrix, so it also involves minors and signs.

Can I enter fractions?

Yes. Enter a fraction such as 1/2 in an entry field. Decimals and whole numbers are also accepted.

Can this tool multiply two matrices?

No. The available operations are determinant, inverse, transpose and adjugate for 2 × 2 or 3 × 3 matrices.

Why does my matrix have no inverse?

Its determinant is zero. This usually means its rows or columns are linearly dependent, so the matrix cannot be reversed.

Why matrix dimensions matter

The order of a matrix is written as rows by columns. A 2 × 3 matrix has two rows and three columns, while a 3 × 2 matrix has three rows and two columns. These are different shapes, even though both contain six entries. The Phademy calculator works with square 2 × 2 and 3 × 3 matrices because determinant, inverse and adjugate are defined for square matrices. A transpose also works for rectangular matrices in general, but the current tool keeps the input to the two square sizes.

Before entering values, count the rows and columns in the question. Read entries left to right across each row. For a matrix written as [[a, b], [c, d]], the first two values belong to row one and the next two belong to row two. Do not enter values column by column unless the original question is explicitly arranged that way.

How cofactors work in a 3 × 3 matrix

To find a cofactor, cross out the row and column containing the entry and calculate the determinant of the smaller matrix that remains. This smaller determinant is called the minor. Apply a sign based on the entry's position. The 3 × 3 sign pattern is plus, minus, plus in the first row; minus, plus, minus in the second; and plus, minus, plus in the third. The checkerboard pattern is essential because a cofactor is not always equal to its minor.

After calculating all nine cofactors, arrange them in the same positions to form the cofactor matrix. The adjugate is the transpose of that matrix. This final transpose is why the adjugate is not simply the matrix of minors. When calculating an inverse, divide every adjugate entry by the determinant. If the determinant is zero, stop: division by the determinant is impossible and the inverse does not exist.

Properties that help check a result

Several properties can help you check matrix work. The transpose of a transpose returns the original matrix: (Aᵀ)ᵀ = A. The determinant of a transpose equals the determinant of the original matrix. If A is invertible, the product A × A⁻¹ is the identity matrix. These are useful checks when studying, even though the calculator does not offer every matrix operation directly.

For a 2 × 2 matrix, you can check an inverse by multiplying the two matrices by hand. For a transpose, compare the first row of the original with the first column of the result. For an adjugate, compare the cofactor matrix and its transpose. These checks can catch misplaced entries that a quick visual scan might miss.

Short practice set

  1. Find the determinant of [[2, 1], [5, 3]]. Calculate 2×3 − 1×5 = 1.
  2. Transpose [[1, 4], [2, 7]]. Swap rows and columns to get [[1, 2], [4, 7]].
  3. Can [[3, 6], [1, 2]] be inverted? Its determinant is 3×2 − 6×1 = 0, so it has no inverse.
  4. Find the adjugate of [[2, 5], [1, 3]]. Swap the diagonal entries and change the signs of the off-diagonal entries: [[3, −5], [−1, 2]].

Use these small examples to check whether you understand the operation before entering a larger matrix. Keep exact fractions if they appear. A rounded decimal may be suitable for a final approximation, but exact values are usually easier to verify during the working.
