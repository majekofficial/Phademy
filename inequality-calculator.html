What an inequality calculator solves

An inequality compares two expressions using less than, greater than, less than or equal to, or greater than or equal to. Unlike an equation, which often asks for one value, an inequality usually describes a range of values. For example, x < 4 means every real number smaller than 4 is a solution. The endpoint 4 itself is not included.

Phademy's inequality calculator accepts one inequality in one variable. It supports linear and quadratic inequalities, returns the solution in inequality and interval notation, and provides a graph to help you see the solution set. Enter a statement such as 2x + 3 ≤ 11 or x² − 5x + 6 > 0. Use one inequality sign in the input. If the variable appears in a denominator, that form is outside the current tool's supported inputs.

The four inequality signs

The symbol < means strictly less than, and > means strictly greater than. The symbols ≤ and ≥ include equality. For example, x < 3 excludes 3, while x ≤ 3 includes it. This small difference changes the endpoint of the interval and the type of point shown on a number line.

You can read x ≥ 2 as “x is greater than or equal to 2”. Its solution includes 2 and every number larger than 2. The statement x > 2 includes numbers larger than 2 but not 2 itself. When typing, you can use the symbols directly or the common keyboard forms <= and >=.

The rule that makes inequalities different from equations

Most steps used to solve an equation also work for an inequality. You can add or subtract the same quantity on both sides, and you can multiply or divide both sides by a positive number without changing the direction of the inequality sign. The important exception is that multiplying or dividing both sides by a negative number reverses the sign.

For example, 3 > 1 is true. Multiply both sides by −2: −6 is not greater than −2. The correct comparison is −6 < −2. The order reverses because multiplying by a negative number flips the number line. Remember this rule whenever a negative coefficient is isolated.

Worked example: a simple linear inequality

Solve: 2x + 3 < 11.

  1. Subtract 3 from both sides: 2x < 8.
  2. Divide both sides by positive 2: x < 4.
  3. Write the interval: (−∞, 4).

The round bracket means 4 is excluded. Values such as 0, 1 and 3 satisfy the inequality; 4 does not.

Worked example: dividing by a negative number

Solve: −2x > 6.

  1. Divide both sides by −2.
  2. Because the divisor is negative, reverse the sign: x < −3.
  3. Write the interval: (−∞, −3).

Check with a value in the solution set, such as x = −4. Then −2(−4) = 8, and 8 > 6 is true. Try x = 0, which is not in the solution set: 0 > 6 is false.

Inclusive endpoints and interval notation

Interval notation is a compact way to describe all values in a range. A round bracket means the endpoint is not included, while a square bracket means the endpoint is included. For x < 4, write (−∞, 4). For x ≤ 4, write (−∞, 4]. For x ≥ 2, write [2, ∞). Infinity always uses a round bracket because infinity is not a real number that can be included as an endpoint.

Read interval notation from left to right. The first value is the lower boundary and the second is the upper boundary. A comma separates the boundaries. If there are two separate solution regions, a union symbol ∪ joins the intervals. For example, (−∞, −3) ∪ (3, ∞) means values below −3 or above 3.

Worked example: a quadratic inequality between two roots

Solve: x² − 5x + 6 < 0.

  1. Factorise the expression: (x − 2)(x − 3) < 0.
  2. Find the critical values by setting each factor to zero: x = 2 and x = 3.
  3. These roots divide the number line into three regions: below 2, between 2 and 3, and above 3.
  4. Test one value in each region. At x = 0, the product is 6, which is positive. At x = 2.5, the product is negative. At x = 4, the product is positive.
  5. The expression is negative only between the roots: 2 < x < 3.

Interval: (2, 3). The endpoints are excluded because the inequality is strict.

Worked example: a quadratic inequality outside two roots

Solve: x² > 9.

Move 9 to the left: x² − 9 > 0. Factorise: (x − 3)(x + 3) > 0. The critical values are −3 and 3. The product is positive when both factors are negative, which happens for x < −3, or when both are positive, which happens for x > 3. The solution is (−∞, −3) ∪ (3, ∞).

How quadratic signs change across roots

For a quadratic expression with two distinct real roots, the roots divide the number line into regions. The sign of the expression can be tested in each region. If the coefficient of x² is positive, the parabola opens upward, so the expression is positive outside the roots and negative between them. If the coefficient of x² is negative, the pattern reverses.

When the inequality includes equality, such as ≤ or ≥, include a root if the expression equals zero there. When the inequality is strict, such as < or >, exclude the roots. A repeated root needs special attention because the expression may touch zero without changing sign. The calculator analyses the supported quadratic form and displays the intervals that satisfy the entered comparison.

Reading the graph and solution set

The graph gives a visual view of the inequality. For a linear inequality, the solution extends in one direction from a boundary value. For a quadratic inequality, the solution may lie between two roots or outside them. The graph helps you connect the algebraic answer to the shape and sign of the expression.

Use the interval notation as the precise statement of the answer. A graph is a visual aid and can be harder to interpret when values are close together or the scale is wide. If a boundary is included, the interval notation uses a square bracket; if it is excluded, it uses a round bracket. Check that this matches the original inequality symbol.

Always true and never true statements

Sometimes simplifying an inequality removes the variable. If the remaining statement is true, every real number satisfies it. If it is false, no real number satisfies it. For example, 2x + 1 > 2x − 5 becomes 1 > −5 after subtracting 2x, which is always true. By contrast, 2x + 1 > 2x + 5 becomes 1 > 5, which is never true.

These are not ordinary one-endpoint intervals. They are special outcomes of the inequality itself. The calculator reports that every number works or that no number works rather than presenting a misleading finite boundary.

Common mistakes to avoid

  • Forgetting to reverse the sign: reverse it only when multiplying or dividing both sides by a negative number.
  • Using the wrong endpoint bracket: strict signs exclude the boundary; inclusive signs include it.
  • Assuming a quadratic has one interval: its solution can be between roots or outside them in two separate regions.
  • Testing only one region: test each region divided by the critical values.
  • Forgetting the original sign: changing < to ≤ changes whether roots are included.
  • Entering more than one comparison sign: this tool expects one inequality at a time.
  • Using a variable in a denominator: this form is not supported by the current calculator.

Applications of inequalities

Inequalities are useful whenever a condition sets a limit rather than an exact target. A budget may require spending to remain below a maximum amount. A student may need a score greater than or equal to a pass mark. A delivery service may accept packages only when their weight is less than a stated limit. In each case, there can be many values that satisfy the condition.

For example, if a student has 42 marks and needs at least 50, the additional marks m must satisfy 42 + m ≥ 50. Subtract 42 to get m ≥ 8. The student needs at least eight more marks. If the assessment has a maximum number of available marks, the solution must also be checked against that real-world limit.

Frequently asked questions

When should I reverse the inequality sign?

Reverse it when you multiply or divide both sides by a negative number. Adding or subtracting the same value does not reverse it.

What is the difference between < and ≤?

The strict sign < excludes the endpoint. The inclusive sign ≤ includes it. The same distinction applies to > and ≥.

What does the union symbol mean?

It joins separate intervals. For example, (−∞, −3) ∪ (3, ∞) means values below −3 or above 3.

Can a quadratic inequality have two solution intervals?

Yes. For x² > 9, the solutions are x < −3 or x > 3, which are two separate intervals.

Can an inequality have no solution?

Yes. If simplifying leaves a false statement, no value satisfies the inequality.

Can every number be a solution?

Yes. If simplifying leaves a true statement, every real number satisfies it.

Can I enter two inequalities at once?

No. Enter one inequality with one comparison sign at a time.

Using a number line to reason about solutions

A number line helps make an inequality's answer visible. Mark the critical value where the expression changes sign or where the two sides are equal. Use an open endpoint for a strict comparison and a closed endpoint for an inclusive comparison. Shade or indicate the side that contains the values that satisfy the inequality. For a quadratic with two roots, mark both critical values and test the intervals on either side and between them.

For x ≥ 2, the point 2 is included and the solution extends to the right. For x < 2, the point 2 is excluded and the solution extends to the left. For x < −1 or x ≥ 3, the answer has two separate regions. Interval notation writes this as (−∞, −1) ∪ [3, ∞). The union symbol means either interval is acceptable.

Testing values is a reliable quadratic method

After finding the roots of a quadratic expression, choose one test value from each region. Substitute it into the original expression, not just into a factor if you are unsure of the sign. Record whether the expression is positive or negative. Then select the regions that match the inequality sign. This method works because a continuous polynomial cannot change sign inside a region without crossing zero.

For example, for (x − 1)(x + 2) < 0, the critical values are −2 and 1. Test x = −3: both factors are negative, so the product is positive. Test x = 0: one factor is negative and one is positive, so the product is negative. Test x = 2: both factors are positive, so the product is positive. The solution is −2 < x < 1.

What happens when a quadratic has no real roots?

If a quadratic expression has no real roots, its graph does not cross or touch the x-axis. Its sign is therefore the same for all real x, assuming the expression is a non-zero quadratic. For example, x² + 1 is always positive, so x² + 1 > 0 is true for every real x, while x² + 1 < 0 has no real solution. This is connected to the discriminant of a quadratic equation: a negative discriminant means there are no real roots.

When a quadratic has a repeated root, the graph touches the x-axis at that point and turns around. The expression may have the same sign on both sides of the repeated root. For example, (x − 2)² is never negative, but it equals zero at x = 2. Therefore (x − 2)² ≥ 0 is true for every real x, while (x − 2)² < 0 has no real solution.

Practice inequalities

  1. Solve 3x − 4 ≥ 8. Add 4: 3x ≥ 12. Divide by 3: x ≥ 4, or [4, ∞).
  2. Solve −5x < 15. Divide by −5 and reverse the sign: x > −3, or (−3, ∞).
  3. Solve x² − 4 < 0. The roots are −2 and 2. The expression is negative between them, so (−2, 2).
  4. Solve x² − 4 ≥ 0. The expression is non-negative outside the roots and includes them, so (−∞, −2] ∪ [2, ∞).

After solving, choose a value from each included interval and substitute it into the original inequality. Also test a value from an excluded interval. This gives you confidence that the interval notation describes the correct set.

Limits of the current calculator input

The tool expects one inequality sign and one variable. It can handle common linear and quadratic examples, including expressions entered with brackets and powers. It does not currently accept a compound statement containing two inequality signs, such as 1 < x < 5, in one input. Solve the two parts separately and combine the results if you need a compound interval.

A variable in a denominator introduces additional restrictions because the denominator cannot equal zero and the sign of a fraction may change across a vertical boundary. That analysis is not supported by this calculator. For example, an expression such as 1/x > 2 should not be entered expecting the same handling as a polynomial inequality. Use a method that explicitly analyses denominator restrictions for rational inequalities.
